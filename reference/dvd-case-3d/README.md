# PARALLAX — 3D DVD Case (CSS-only prototype)

A standalone visual experiment: a fictional sci-fi DVD case built
entirely from CSS 3D transforms. No frameworks, no WebGL, no build step.

## Run it

**Option 1 — just open the file**

Double-click `index.html`, or drag it into a browser window.

**Option 2 — tiny local server (recommended on some browsers)**

```bash
cd dvd-case-3d
python3 -m http.server 8080
# then open http://localhost:8080
